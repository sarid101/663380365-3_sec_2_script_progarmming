# mini Project — ระบบสั่งอาหาร (Food Ordering System)

**งานกลุ่ม** — โค้ดและเอกสารทั้งหมดอยู่ใน repository ของกลุ่ม:

### 👉 [github.com/Kittynakaa/miniproject](https://github.com/Kittynakaa/miniproject)

## สรุปโปรเจกต์

ระบบ POS (Point of Sale) สำหรับรับออเดอร์อาหารหน้าร้านและออกใบเสร็จอัตโนมัติ เขียนด้วย Python แบบ command line รันบน Google Colab

- ระบุชื่อลูกค้า / หมายเลขโต๊ะ
- ดูเมนูแยกหมวด (อาหาร / เครื่องดื่ม) และค้นหาเมนูตามชื่อ (ไม่สนตัวพิมพ์เล็ก/ใหญ่)
- สั่งอาหารลงตะกร้า พร้อมเลือกจำนวน ระดับความเผ็ด/หวาน และท็อปปิ้ง
- จัดการตะกร้า: ลบรายการ และเรียงตามราคาสูง–ต่ำ
- คำนวณยอด: ส่วนลด 10% เมื่อครบ 300 บาท + VAT 7% แล้วพิมพ์ใบเสร็จพร้อมวันเวลา
- บันทึกเมนู ท็อปปิ้ง และประวัติออเดอร์ลงไฟล์ JSON (`orders.json`)

**เนื้อหาที่ใช้:** list / dict, ฟังก์ชัน, การค้นหาและเรียงข้อมูล, `datetime`, อ่าน/เขียน JSON
